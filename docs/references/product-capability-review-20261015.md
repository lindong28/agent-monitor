## 覆盖及未核实边界

- 实际样本为 1 个 Hub、2 种 persona（分摊路径，不是各自全量重复）、3 种日期语义（7d、30d、custom 深链）、2 种搜索状态（命中/空态）、2 个会话复制失败样本。窄/宽对照为 390×844 与 1440×1000；worker 主要交互另用 1280×720。未覆盖所有账号、机器、时序和筛选组合，不作全站无缺陷断言。
- 自定义日期原生输入两次未能通过自动化填入，属于验证路径未核实，不能报产品缺陷。正确 `range=custom&start=2026-10-01&end=2026-10-07` 深链回填日期，点击进入会话仍保留日期并显示 349 条结果；错误的 `start_date/end_date` 参数尝试不作为产品证据。
- 全局搜索实际覆盖会话/安装命中、无匹配空态、清空和关闭。安全展开覆盖机器状态、成本说明、周期比较、历史账号、既有批次/帮助、第一条会话记录。未逐项点击透视五预设、分组、有效结果上的指标切换、三张趋势/分布数据表、全部 guide 锚点、单账号操作详情和详情分页。
- 1600×900、1280×720、1024×576 仅模拟缩放对应 CSS viewport，不是实际浏览器 zoom。同步面板展开时 KPI 顶边约 y847，三个样本首屏均无完整 KPI，与既有 ISSUE-UX-20260915-a1c2 的占屏形状一致；没有据此给全部视口的视觉质量结论。未覆盖主题、所有窄屏页面与完整图表审美。
- 未执行账号写动作、安装、服务变更；未测后台刷新长时间保持展开、冷热缓存升级、精确交互时延或性能。既有 ISSUE-UX-20261014-6c31 保留，不能因本轮没有持续复现而关闭。
