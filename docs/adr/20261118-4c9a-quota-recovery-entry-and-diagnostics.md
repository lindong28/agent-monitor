# Current quota recovery entry and bounded client diagnostics

The reported MacBook pause recurred after an earlier successful recovery. Its two permitted quota RPC opportunities were exhausted, and the saved generic transport error did not distinguish the failing network layer. The saved 512-character stderr prefix was occupied by startup configuration warnings. A separately approved, same-account quota-only recovery succeeded through the existing owning-machine route; that result does not identify the original cause.

Keep the existing 64 KiB retained stderr and 512-character stored excerpt limits. Retain the first 32 KiB plus a rolling final 32 KiB when capture overflows, discard incomplete lines at both capture cuts, apply credential redaction before the display limit, and explicitly mark middle omission. Keeping only the tail would lose startup context; increasing the prefix limit would enlarge retention while still allowing startup noise to displace later output. No free-form client log determines authentication, retry, pause scope or recovery eligibility. Existing records are not rewritten.

Turn each current machine pause on Overview into a link to that machine's current recovery card on Collection. Reuse the normal read-only status endpoint and existing explicit egress confirmation for any provider action. The card must be available without a historical failure row, remain intact during snapshot refresh, and cancel pending status reads when leaving the page. Existing collection and account recovery entrypoints remain available.

The decision received one independent review on 2026-11-18. Acceptance covers long startup output, oversized single credential lines, bounded redaction, current-pause navigation without historical errors, retained cards and cancelled reads. Real provider recovery, automatic scheduling, deployed browser consumption and the generic transport root cause remain separate evidence. This decision does not increase retries, change identities or egress, or authorize automatically clearing an existing pause.
