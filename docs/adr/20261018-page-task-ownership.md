# 页面按用户任务归属

状态：2026-10-18 用户已授权；实现与真实部署验收分开报告。

用户要求在页面级隔离独立排障任务，并同意先改 harness，再全面检查和优化 Agent Monitor Web UI。该授权取代契约 G1/G2 的 Overview/Explore 逐机卡片位置，以及 G4d / 9c42 的账号表外同区位置约束。旧 ADR 与历史验收不改写，身份、覆盖、未知、计价和低余量警示语义继续有效。

采集与诊断页拥有机器采集详情、全部留存历史质量、未归属账号的机器配额观测。Overview、Explore、Sessions 保留影响当前判断的覆盖与时效说明；Overview 保留适用的低余量警示，已知历史账号仍属账号比较。Guide 提供接入说明和诊断入口。

迁移入口保存完整来源 URL，包括日期、筛选、会话详情与 fragment；总览配额的筛选、历史组、账号观测和操作区展开状态编码到返回地址。诊断返回链接只接受本源已知页面。来源日期仅用于返回，全部历史质量不按该日期筛选。主导航、页面搜索和会话详情均有入口。

`/api/collection` 通过同一个 admitted view 复用既有 sync / live rate_limits authority（不调用账号记忆 upsert）。直接复用 Overview 会额外计算今日、本周、范围汇总、趋势和模型/目录聚合，这些查询不服务诊断任务，因此选择窄投影入口。既有持久 schema、采集调度、计量、身份和保留逻辑不变。按钮只重新读取，不启动 quota refresh；页面沿用既有可见页 30 秒刷新与离页清理。

隔离 fixtures 覆盖路由、读取边界和返回上下文；真实宽窄屏、键盘、展开/刷新和生产版本由本轮发布者另行复验。源码与测试不表示已部署。

独立审查补充：未登录且没有参与当前账号读数的机器清单仅在诊断页展示；当前显示来源登录失效的影响仍在账号区可见。账号操作详情仅选择该 operation 的 before/after 观测，标明本次操作范围；总览账号比较继续使用独立的最新配额，不覆盖历史操作证据。配额筛选不改变发送选择集，发送区明确两者独立。
