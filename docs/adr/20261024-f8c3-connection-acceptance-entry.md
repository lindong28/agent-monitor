Provide an explicit project acceptance entry using the existing six-account fixture and a caller-supplied browser-task tool. This is a development dependency only; product runtime remains independent of ai-agent-config. Default acceptance checks actual browser pairing, preview, cancellation, and explicit confirmation through fixture request counts. No real provider or credential store is used.

It checks loaded, connected, byte transfer, KeepAlive recovery, unload and listener closure separately, and cleans up on failure. Using the formal service would contaminate production; unit tests alone cannot reproduce the browser popup and launchd boundaries observed in the 20261024 device-connection UX record. Scope excludes Chrome system-proxy equivalence, login/reboot, real account requests and non-macOS lifecycle support. These new entrypoints remain unverified at decision time; current commands and acceptance results will be documented after execution.
