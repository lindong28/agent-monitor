# 保留批量发送并收敛上游请求

2026-10-21。独立决策审查一轮，七项成立；实施前记录。

用户要求保守降低账号损失风险，同时明确保留 Web 批量发送以尝试触发额度窗口。保留每账号一条固定短消息，完整账号串行，前一子进程清理完才启动下一项；保留 2 秒最小启动间隔与发送阶段 120 秒预算。消息完成与服务端返回 reset 时间分开呈现，不保证窗口因此固定。随机措辞、模拟人工不能替代减少不必要请求。

同一部署 state 下 Codex、Claude 各用独立跨进程通道；开始前检查持久本地暂停，结束前保存失败。未知结果、认证拒绝、限流和不可安全归因的上游失败暂停后续操作，不自动补查或重发；崩溃留下活动记录时按未知暂停。已知额度不足仅限制对应账号发送。明确本地缺登录不申请设备码；登录由单独按钮触发，完成后不续发。清登录不解除限制。手动解除只确认本地暂停，不证明上游恢复，不擦历史失败、不自动调用。

这取代既有 ADR 中自动登录后续发、失败后自动补查和八账号并发的调度政策；保留身份与目标配额桶校验、固定批次不重发、HTTP-only 私有 provider 和原始结果。私有 provider 的 request_max_retries 与 stream_max_retries 设为 0：官方 0.162.1 model-provider-info 源码接受零，作用域仅发送 alias，不能据此声称认证和配额内部无重试。

机器配额删除统一重试，Claude 认证拒绝后不轮换 token。Hub 按机器串行查询 combined payload，异常停止当前轮剩余机器，明确会延后另一 provider 的后续机器读取；这不是全局持久停用。累计预算按机器数和单机 140 秒上界推导并同步父等待者，未尝试机器明确报告且不更新观测时间。重复请求合并当前轮。各主机自主 collector 仍无跨机器分布式互斥。

公共网络诊断合并并发和失败缓存，force 不绕过 60 秒保护，HTTP 非成功明确失败并尊重可读 Retry-After；价格 TLS 校验失败使用既有 fallback，不降低证书验证。

两个 provider 的有界 JSON 与稳定文件锁沿用本机原子文件存储，不引入数据库。所有测试隔离 HOME/state，用固定 stdio/HTTP 替身并禁止外网。实际封禁原因、供应商规则、真实恢复、CLI 全部内部尝试及跨机器全局调度未核实。本次不部署，不整合运行主树，不发真实消息。
