# 账号配额的展示筛选

Status: accepted for local implementation, 2026-10-07. Publication and deployment remain separate.

## 背景与决定

Web UI 路线图阶段 4.5 参照真实 Vercel AI Gateway Budgets & Spend 的对象分类、搜索和逐对象用量展示。用户选择“观测与规划”，不改变账户操作、采集周期或后端限额机制。

总览现有配额区增加全部／Claude／Codex 筛选、账号／套餐／机器搜索和匹配计数。当前账号与历史账号分别计数，未识别记录保留其机器语义。现有七列表格、原始百分比、重置时间、陈旧提示、历史折叠与删除确认保持。来源失败与登录失效提示不受筛选隐藏，过滤无匹配与尚未取得数据有不同文案。页面时间范围不控制服务商配额窗口，不跨账号相加或平均百分比。

## 备选与后果

单独新建配额页会重复现有数据和操作入口；仅调样式不能缩短多账号定位。持久预算、通知与硬限额不在用户此次选择之内。沿用 G4、91da 和 c814 的数据与操作边界。

## 审查和未验证项

独立决策审查七项成立；设计基线 4221af9，最终实现接入 7bd82b4 的批量账号与发现能力。定向 renderer 测试覆盖 2 Provider、5 记录、当前／历史／未知身份、3 类筛选、搜索、轮询与页面返回；原有 Web 静态套件 39 项通过。独立实现审查发现的“删除响应在筛选隐藏行后返回”与“仅 unavailable_reason 的失败被筛选隐藏”均先复现失败、修复后同测试通过；完整快照仍按原身份与观测时间匹配。

隔离浏览器实际使用筛选、零匹配、清空与历史展开；1440px／390px 观察保留局部表格横滚、无整页横向溢出。五记录合成页的 Provider 切换下一帧读数为 34.8ms／49.0ms（首次／重复各一次，no-op 对照不变），不代表生产采集性能。真实总览实施前已读取逐账号、历史与陈旧／采集失败提示；最终上线另验。其他会话负责后端性能、采集和断言问题。
