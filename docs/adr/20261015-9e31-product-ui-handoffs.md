# 产品分析下钻与紧凑状态呈现

Status: accepted, 2026-10-15. 用户在能力审查后明确要求按建议改进；L1 独立审查七判据成立，无 blocker。实现和生产验收尚待完成，不以本决定证明上线效果。

## 决定与依据

沿用 [实施计划](../../plans/20261015-product-ui-improvements/plan.md) 的范围、备选、成本和验收：新增 `unknown_cost` 统计指标，以现有 `entry_count - cost_known_count` 派生；排名可进入 `cost_status=unknown` 的会话列表，分组前只保留 `cost_usd is None` 的事件，详情仍展示完整保留记录。未知包括缺价格和不完整用量，不等同未知模型；历史汇总与保留明细不保证一致。

配额在窄屏纵向显示同一账号的七字段，桌面维持表列；来源、身份、历史分区、原始百分比与时间不变。本次替代 [b45f](20261007-b45f-quota-explorer.md) 的窄屏横滑呈现，其他决定继续生效。同步详情默认折叠，顶部摘要点名需关注机器、保留计入覆盖及汇总旁影响提示，手动展开所有机器与技术详情。基于结构状态给处置提示，不用异常字符串推断根因。

独立新页面会重复分组及会话能力；全量明细聚合既增加读取也丢失更早汇总；仅缩列或提示横滑不能同时读账号与额度；将同步面板移至页尾会使覆盖提示远离汇总。故选现有路径衔接与局部响应式布局。

证据来自 [能力审查](../references/product-capability-review-20261015.md)：两个 HTTP 复制失败、390px 表格 334/1040px、展开同步面板将 KPI 推至 y847。保留 [a7c2](20261014-a7c2-known-cost-coverage.md) 的已知小计与 Sessions 严格总额规则，未知不归零。周期两期链接与余额多优先仅帮助导航和挑选，不承诺账号可用。

## 作用域与未验证

范围为六项建议及五页共用同步呈现，不改变计费算术、DB schema、归档、采集/轮询周期或账号动作。部署按项目既有入口。决策时新数据链路、窄屏可读性及复制实际内容尚未验证；后续由实施者在隔离环境及真实消费者入口分别验证。独立报告保存于 `/Users/lindong/task-artifacts/agent-monitor-ui-improvements-20261015/decision-review.md`。
