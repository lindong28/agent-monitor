# 面向任务的费用与采集诊断

状态：2026-10-19，用户授权全站优化，一轮独立决策审查放行，无 blocker / 应修。

用户要求：“全面审查并优化……所有页面及展开内容……让界面简洁易懂、风格一致，信息和操作服务于核心用户任务，保留必要信息和现有功能。直接完成修复、部署和逐页复验。” 本决定只改变呈现，不改变计价、数据纳入、采集或账号操作。

修订 [8c42](20261018-8c42-cost-diagnostics.md) 的透视逐组“已知小计”呈现要求：与总览共用可见费用口径，非空排名不逐项重复限定；没有可计价金额仍明确标注，已知零、未知指标、分期明细和会话钻取保持原义。依据是本轮全站授权，不是把先前仅总览的授权外推。

诊断页先展示机器状态、数据时间和实际失败，再展示费用原因。历史质量数量保留在机器展开区。价格、模式、冲突、原因未记录等默认展示；缺少完整用量的记录保留数量、分组和钻取，默认折叠。条数不代表漏计金额，不声明全部不可恢复。重读保留展开状态。窄屏复用指南和会话的字段卡片，使原因、机器、模型、条数和链接同卡可读。

不采用删除底层记录、删除未知指标、折叠全部诊断或新增页面：前两者丢能力，全折叠遮蔽需排查的价格/来源问题，新页面没有额外任务收益。仅缩短文案不能消除逐项重复。网络检测边界、会话扫描/留存范围、配额历史/失效状态、账号操作和结果继续保留。

总览合并重复价格解释；指南周期比较指引改为实际存在的日期、金额和 token，未知原因从费用诊断取得。作用域及逐页验证见 [本轮审查](../references/product-capability-review-20261019.md)。真实发送、授权、清除登录态及 provider 刷新不在本轮实测内；源码和隔离测试不代表生产已生效。
