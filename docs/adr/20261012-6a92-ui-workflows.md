# Web UI 范围、比较与会话追溯

状态：Accepted。2026-10-12 用户授权处理产品缺口；L1 独立决策审查首轮复核，F1/F2 修正后放行。实现和 MacStudio 有界真实交互验收已完成，见运维记录。

## 背景与选择

现有页面已有观察能力，但固定周期图卡继承全局日期，透视排行不能进入对应会话，加载后的调用页丢失 Gateway 来源限定，网络检测缺少服务端身份。新使用者缺少接入说明，周期变化与账号余量也需要额外人工比较。

采用现有页面与数据源的增量改进：明确来源、非账单成本与检测主机；固定图卡传递实际日期；排行带维度和日期进入会话；提供只读接入说明；按需比较完整日窗口；配额按最终显示读数排序。保留按需完整筛选、独立配额读数和已准备聚合视图。替代方案包括仅改卡片标题、全站重设计与配置向导、自动全量分析、比较含未完结的今天、自动切换账号；这些分别不能恢复图表语义或增加不必要的范围、查询成本和副作用。

## 语义与边界

周期比较使用 Asia/Shanghai 中最近 N 个完整日及此前 N 日，不含今天，明确两期日期。全部历史没有等长前期。两期共用 admission，保留无记录、无已知成本、已知零和混合未知的区别，只展示已知成本差额，不生成百分比；覆盖完整性未知，最早历史日期不能证明连续覆盖。金额为记录或估算，不能据此认定实付或优化收益。

会话列表先在后端按日期和使用记录的维度过滤，再聚合会话；列表金额与 token 仅表示匹配部分，详情仍含全部留存记录。当前筛选不因无匹配而静默重置。Gateway 没有编码会话身份，不伪造跳转。

配额排序保留服务商及在用/历史分组，未知置后，使用机器与 Web 最新观测合并后的最终读数；过期重置不视为未来重置，不触发账号动作。

不改快照 schema、身份、留存、定价算法、外部 Gateway 或采集周期。替换 UX 契约 A2/B5 中固定图卡继承全局日期的行为。当前筛选等待与采集锁超时需现场核实；源码、测试和运行证据分别记录于任务计划与运维文档，不把本决策当作完成证明。

部署时真实会话详情出现跨机大响应截断；按固定完整记录语义补 HTTP gzip 协商，保留不接受压缩的客户端原响应。不把压缩等同于减少查询工作；无新增数据 schema 或外部依赖。
