# 方舟模板顶层导航与文档展示适配

日期：2026-10-14。基线：91cc8e4d1e6548be960db9bd68c41a586d6df0cc。状态：一轮独立 L1 决策审查七项成立，放行；实施与线上读数另记于 design.md 和 operations/services.md。

用户要求基于更新后的方舟模板更新 Agent Monitor Web UI。采用顶部「控制台／使用与接入」区域导航，控制台保留四个数据页面的局部导航，指南展示章节、目录与可复制命令。顶部搜索仅索引已有页面和帮助条目，不查询账号或后台。相比把五个入口平铺在顶栏，两区域能表达数据工作台与说明文档的差别，保留原五路由。模型目录、Gallery 与订阅购买没有对应业务，不纳入本次实现。

采用模板当前的顶栏、搜索浮层和文档代码展示；延续 7d2f 的视觉基线、e781 的会话返回上下文、b45f 的配额局部搜索和 b97e 的独立产品边界。控制台返回地址保留完整 URL；普通跨页日期仍按既有规则传播，hash 由浏览器处理。SPA 只替换 main，因此区域选中态和局部导航须同步更新。指南三处 Gateway 过时描述属于基线独立且命中既有产品边界，在本次重排中移除。

范围限于五路由及会话详情的共享壳层、指南与本地搜索；不改变 API、采集、计量、账号、运行依赖和请求生命周期。搜索每次输入仅过滤固定的小列表，无新增 I/O 或定时任务。实现由当前线程处理，独立审查复用原决策 reviewer；不引入额外评测或审查机制。

决策依据为实际 HTML 和 SPA 源码、当前模板定义及既有 ADR 的浏览器记录。新导航、搜索、复制和桌面／窄屏效果尚未实现和验证，旧测试结果不证明新行为正确。实施后验证完整 URL 返回、前进后退、两种宽度、搜索空态与清空、Escape 和焦点恢复、复制实际文本，再按已授权的发布流程 push 和部署。未处理 finding：无。
