# Product visual design

This mutable record describes the shared visual layer and its observed application. Future pages inherit this layer; page-specific task layouts and business contracts remain in their existing owners.

## Effective design

The selected style for the current source changes is Prompt Planet `style:vercel-gateway-console` v2. Its definition is the matching entry in `/Users/lindong/research/prompt-templates/library/webui/templates.json`, with the associated `assets/vercel-gateway-console-v2/index.html` example and v2 application/review prompts. The build exposes the frozen definition at `/api/webui/v1/templates/vercel-gateway-console/2.json`. As of 2026-10-09, the v2 definition is published at https://prompts.aiplanet.live/api/webui/v1/templates/vercel-gateway-console/2.json and the implementation below is deployed to MacStudio; the dated live evidence records the sampled coverage. The historical v1 application and production evidence below remain v1 evidence. Commercial-site access is not required for template application. Overview and LLM Calls retain the existing `usage-observability-console`, `record-explorer`, and `request-diagnostics` v2 structures; the product style overrides their visual defaults. Explore, Sessions and Network need no additional scenario template.

`web/styles.css` is the shared entry point for all five routes, including dynamically rendered details. New pages use the existing `.main`, `.page-title`, `.panel`, form, table and disclosure classes. There is no page opt-in class or template runtime dependency. Shared defaults are system sans-serif 14/22px text, 24/32px page titles, 16/24px section titles, 28/36px primary metrics, 12px supporting text, 36px controls, 8px corners, white surfaces, neutral canvas and light dividers. Normal panels have no elevation shadow. Navigation uses a neutral selected surface; the common Refresh action uses a dark fill. Tables use 12×16px cell padding and local scrolling.

| Rule | Effective application and reason |

Batch instructions and secondary account readings move into disclosures while costs, failures and actions needing attention remain visible. Refresh/account writes are excluded from this style validation. |
