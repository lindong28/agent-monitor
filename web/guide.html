使用与接入

先确认数据来自哪里

agent-monitor 面向个人开发者、多机使用者和 Gateway 开发者，汇集用量、会话、配额与诊断信息。金额是记录或估算，不是服务商账单。

首次接入

  1. 在自己的 agent-monitor checkout 中配置 machines.json；新单机安装只保留自己的本机条目，例如 {"machines":[{"name":"local","ssh_host":"localhost","self":true}],"retired_names":[]}。已有安装须保留机器身份和退休记录。
  2. 准备 Python、Git 和 curl。Monitor 可独立安装和运行，监控 Claude Code / Codex 的用量与会话。
  3. 运行 ./install.sh，再运行 agent-monitor start。首次采集可运行 agent-monitor refresh；macOS 定时采集由安装器设置，Linux 需自行安排调度。
  4. 多机使用需配置自己的 hub.json 角色、URL、SSH 目标，在各机运行 ./install.sh hub <机器名>。Hub 拉取快照，采集器独立保存本机数据。

完整命令、依赖与已有服务迁移见 checkout 的 README.md 和 docs/operations/services.md。本页只说明与检查状态，不修改配置或登录账号。

从问题找到证据

  • 想知道成本变化：总览展开周期比较，核对两个周期日期与未知定价，再进入透视定位目录、模型或机器。
  • 想追溯某组用量：点击透视排行的“查看会话”。列表只计匹配记录；打开详情可看全部留存记录。汇总比明细更完整时，差额不能当成查询错误或零成本。
  • 想挑选账号：在总览按配额窗口和剩余额度排序，同时核对更新时间。历史账号读数不代表当前可用。
  • 页面为空：先检查日期和筛选，再看机器采集状态、Gateway 来源状态及 exporter 版本。连接失败会保留最后成功快照；修复接入后再刷新。

请在可信个人网络使用；账号操作的来源检查不等于用户认证。开源代码与公开运行中的仪表盘是两件事。
