单机使用

开始前，准备 Python 3（含 venv 和 pip）、Git 和 curl，并进入自己的 agent-monitor 代码目录。

  1. 配置 machines.json。如果是新单机安装，只保留自己的本机条目，见下方示例。如果是已有安装，须保留机器身份和退休记录。
  2. 运行 ./install.sh 安装 Monitor。
  3. 运行 agent-monitor start 启动服务。
  4. 运行 agent-monitor refresh 进行首次采集。
  5. 运行 agent-monitor open 打开页面。进入「采集与诊断」，确认机器名称、快照是否可读及数据更新时间。

macOS 安装器会设置定时采集。Linux 用户需另行配置定时任务。

新单机 machines.json 示例
{
  "machines": [{"name": "local", "ssh_host": "localhost", "self": true}],
  "retired_names": []
}
单机安装与首次采集
./install.sh
agent-monitor start
agent-monitor refresh
agent-monitor open

若快照不可读或更新时间未变化，先查看采集详情中的错误，再检查对应配置与连接。

多机接入 · Hub 与采集器

Hub 负责拉取快照；采集器独立保存各机数据。开始前，确认 Hub 能通过 SSH 连接各采集器。

  1. 在 machines.json 中配置机器名称与 SSH 目标，在 hub.json 中配置 Hub、URL 和采集机器。已有安装须保留机器身份和退休记录。
  2. 在每台机器的代码目录中运行以下命令。将占位符替换为该机器在配置中的名称。
多机安装 · 替换为配置中的机器名
./install.sh hub <机器名>

安装后，进入 Hub 的「采集与诊断」，逐台核对机器名称、纳入状态与数据更新时间。显示旧快照时，按该机器的错误继续排查。

完整命令、依赖与服务迁移见代码目录中的 README.md 和 docs/operations/services.md。
