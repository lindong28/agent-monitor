维护说明：历史数值为什么会变化

最近 28 天的合计可能随新数据和重新估算变化。每次更新按以下规则处理：

  • 能读取数据源时，重新计算最近 28 天的数据。
  • 已有日志记录金额的，保留原金额；其他记录按 agent-monitor 当前的配置价格估算。
  • 数据源缺失或计数减少时，保留上次可信值；其他数据照常更新。
  • 28 天以外的数据保留历史值，不再重算。

如何授权、继续发送或开始新一轮

需要授权时，先在账号安全设置中启用设备码登录，再打开对应账号卡片中的 OpenAI 官方授权页并填写设备码。确认登录账号与卡片邮箱一致后完成授权。

配额表显示同一账号最新的读数，展开“配额更新”可查看时间与来源。仅限可信私人网络使用：能访问本服务的人可操作这些账号。
