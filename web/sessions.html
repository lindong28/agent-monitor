这张表包含什么

仅计已观测用量，不保证最终 usage。Codex 模型为请求或配置值，实际路由模型未知；估值使用计算时价格，非历史实际费率。明细可查看 usage 证据及金额依据。

会话目录按启动目录归类，可能显示其 Git 仓库标识；同一会话中的跨项目工作不拆分费用。

定价未知的行显示 —；标 推算 的 Codex 与 GLM-5.1/5.2 行按打包定价推算，不是精确账单。

已采集的会话统计不随本地日志清理而丢失，但采集前就删掉的历史找不回来。未升级 exporter 的机器不在其中。

列表只计日期与筛选匹配的已观测记录；详情含完整留存。成本非账单；未知不归零，汇总与明细可能有覆盖差异。
